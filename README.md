# Student Grading System 🎓

A Python-based Student Grading System designed to calculate and display student grades from their academic scores.

## 📌 About the Project

The Student Grading System is a simple Python application that helps simplify the process of calculating student grades after scores have been entered.

The project was built as part of my Python development journey and demonstrates my understanding of Python programming, logic, functions, and handling user input.

## ✨ Features

* Enter student information and scores
* Calculate grades based on scores
* Display the student's grade
* Simple and easy-to-use workflow
* Built entirely with Python

## 🛠️ Technologies Used

* **Python**
* **VS Code**

## 🚀 Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/christianjoetechrise/student_grading_system.git
```

### 2. Navigate into the project

```bash
cd student_grading_system
```

### 3. Run the program

```bash
python main.py
```

> If your main Python file has a different name, replace `main.py` with the correct filename.
